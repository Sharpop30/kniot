## שלב 1: העלאה ל-GitHub Pages (פעם אחת)

1. github.com ← **+** ← **New repository**. שם: `kniot`, Public, צור.
2. בעמוד הרפו: **Add file ← Upload files** ← גרור את **כל** הקבצים מהתיקייה (חוץ מקבצי הגיבוי, אם לא רוצים) ← Commit.
3. **Settings ← Pages** ← Branch: `main`, תיקייה `/ (root)` ← Save.
4. אחרי כדקה הקישור יופיע למעלה: `https://<שם-המשתמש>.github.io/kniot/`

הרפו ציבורי אבל מכיל רק קוד. **הנתונים שלכם לא נמצאים בו**. הרשימה נשמרת ב-Gist פרטי.

### עדכון גרסה
אותו מסך: **Add file ← Upload files** ← גרירת הקבצים המעודכנים ← Commit. תוך דקה זה באוויר.

בטלפון: סגרו את האפליקציה **לגמרי** (החלקה למעלה במסך המתגים, לא רק חזרה למסך הבית) ופתחו שוב. כדי לוודא שהעדכון הגיע: ⚙ ← תחתית המסך ← השוו את מספר הגרסה לזה שכתוב בראש המסמך הזה.

## שלב 3: סנכרון בין שני הטלפונים

### יצירת Token (פעם אחת)
1. github.com ← תמונת פרופיל ← **Settings** ← **Developer settings** (בתחתית) ← **Personal access tokens ← Tokens (classic)**.
2. **Generate new token (classic)**. שם: `kniot`, Expiration: **Custom, שנה קדימה** (לא No expiration, כדי שטוקן שדלף לא יישאר פעיל לתמיד), וסמנו **רק** את התיבה **gist**.
3. Generate ← העתיקו את ה-token (מתחיל ב-`ghp_`). הוא מוצג פעם אחת בלבד.
4. כשהתוקף מתקרב: באותו מסך פותחים את הטוקן ← **Regenerate token**, ובכל טלפון ⚙ ← ניתוק ← הדבקה ← חיבור. הרשימה לא נפגעת. הטוקן הנוכחי פג ב־26.9.2027, ותזכורת לחידוש קבועה ביומן גוגל ל־19.9.2027.

**אבטחה:** הטוקן לא נמצא בקוד ולא במאגר בגיטהאב. הוא נשמר רק בזיכרון של כל טלפון שהודבק בו. הרשאת gist חלה על כל הגיסטים בחשבון, ולכן כדאי שרשימת הקניות תישאר הגיסט היחיד בו.

### חיבור
בכל אחד משני הטלפונים: ⚙ ← הדביקו את **אותו** token ← **התחברות**.

מרגע זה שניכם רואים ומעדכנים את אותה רשימה. נקודה קטנה ליד הכותרת מראה את מצב הסנכרון:

| הנקודה | מה זה אומר |
|---|---|
| ירוקה | מסונכרן |
| כתומה מהבהבת | מסנכרן כרגע |
| **חלולה אפורה** | **אין רשת. הכל שמור במכשיר ויעלה כשהחיבור יחזור. לא תקלה** |
| אדומה | תקלה אמיתית (טוקן פג, הרשאה נשללה). כדאי להיכנס ל-⚙ |
| לא מופיעה | לא מחוברים לסנכרון |

ב-⚙ מופיעה גם שורת מצב במילים: "מסונכרן לפני 3 דקות", או "אין רשת · 2 שינויים ממתינים להעלאה".

## שימוש

| פעולה | איך |
|---|---|
| הוספת פריט | ＋ בפינה ← הקלדה ← Enter. פריט חדש מהבהב לרגע במקום שבו נחת |
| **חיפוש** | ההקלדה בשדה ההוספה **מסננת את הרשימה תוך כדי**. מקלידים "מעד" ורואים מיד את "מעדנים" עם הכפתורים שלו. סימון ○ או ⊗ על תוצאה סוגר את החיפוש. ✕ בתוך השדה מנקה אותו. אם אין התאמה, Enter מוסיף פריט חדש. ההשלמה האוטומטית מציעה רק שמות שקניתם בעבר ושלא נמצאים כרגע ברשימה |
| החזרת פריט שנקנה | מקלידים את שמו ו־Enter, או מחפשים ומקישים ○. ההודעה תהיה "חזר לרשימה" |
| הוספת כמה בבת אחת | הקלידו `חלב, לחם, ביצים`, או **הדביקו רשימה שלמה** (למשל מוואטסאפ, שורה לכל פריט). הכל נכנס כפריטים נפרדים בפעולה אחת, ו"בטל" מבטל את כולם ביחד |
| קניתי | הקשה על ○. הפריט מקבל קו חוצה והתווית "נקנה" |
| אין במלאי | הקשה על ⊗. הפריט מעומעם ומקבל את התווית "חסר", ונשאר ברשימה לפעם הבאה |
| עריכת שם | **לחיצה ארוכה על השם** (חצי שנייה). Enter או נגיעה בחוץ שומרים, Escape מבטל |
| כמות | + ליד השם. משעולה מ-1 מופיע גם − |
| מחיקה | גרירה שמאלה |
| **דחוף** | **גרירה ימינה**. הפריט מקבל תגית כתומה "דחוף" ועולה לראש מה שנשאר לקנות. גרירה נוספת מבטלת. הסימון יורד לבד כשמסמנים ○ (נקנה), ונשאר אם מסמנים ⊗ (חסר), כי עדיין צריך להשיג אותו. גרירה ימינה על פריט שכבר נקנה מחזירה אותו לרשימה כדחוף |
| דחוף בהקלדה | **סימן קריאה בסוף השם**: `חלב!`. עובד בהוספה, ברשימה עם פסיקים (`לחם, ביצים!`), בהדבקה ובעריכת שם. אם הפריט כבר ברשימה, הוא פשוט מסומן דחוף |
| **סבב חדש** | ↺ בפינה מנקה את **כל** הסימונים ומשאיר את הפריטים, כדי לקנות שוב את אותם מוצרים בלי להקליד מחדש |
| ביטול | אחרי מחיקה או ↺ מופיעה למטה הודעה עם "בטל". הקשה עליה מחזירה את המצב |
| מראה | ⚙ ← אוטומטי / בהיר / כהה |
| עזרה | ⚙ ← השורה **איך משתמשים** בראש מסך ההגדרות, עם כל הסימונים והמחוות. בפעם הראשונה שפותחים את ⚙ במכשיר חדש היא נפתחת מעצמה. מאותו רגע שורת ההסבר בתחתית המסך הראשי מתקצרת ל"כל הפעולות מוסברות ב־⚙", והקשה עליה פותחת את המדריך |

**הקשה על גוף השורה או על השם לא עושה כלום.** רק ○ ו-⊗ מסמנים. זה בכוונה, כדי שלא יסומנו פריטים בטעות תוך כדי גלילה.

**סדר הרשימה:** למעלה מה שעדיין צריך לקנות, באמצע מה שסומן חסר, ובתחתית מה שכבר נקנה. **בתוך כל קבוצה הדחופים ראשונים, ואחריהם סדר אלף־בית**, כשאות סופית נחשבת כמו רגילה ומספרים ממוינים לפי ערכם ("גבינה 5%" לפני "גבינה 9%"). פריט שמסמנים **לא זז מיד**: הסימון מופיע במקום, ורק אחרי חצי שנייה, כשהאצבע כבר הורמה, השורה מחליקה למקומה החדש. שינוי כמות או עריכת שם לא מזיזים פריט בכלל.

הרשימה היא תבנית קבועה, לא רשימה חד-פעמית: הפריטים נשארים בה גם אחרי שנקנו. בתחילת קנייה חדשה לוחצים ↺ והכל חוזר להיות "צריך לקנות". מוצר שכבר לא קונים מוחקים בגרירה.

> **שימו לב בשימוש משותף:** ↺ משפיע על שני הטלפונים. אם אחד מכם בסופר באמצע סימון והשני לוחץ ↺ בבית, הסימונים יימחקו אצל שניכם תוך שניות. "בטל" בהודעה מחזיר את זה.

## איך הסנכרון עובד

- כל שינוי נשמר לענן תוך ~3 שניות.
- בכל פתיחה או חזרה לאפליקציה היא מושכת עדכונים, **וגם כל 30 שניות כשהאפליקציה פתוחה לפניכם**, כך ששינוי מהטלפון השני מופיע מעצמו בלי לצאת ולחזור. הרענון הזה שקט: הוא לא מהבהב ולא מצייר מחדש אם לא השתנה כלום, ונעצר כשהאפליקציה ברקע או כשאתם באמצע גרירה או עריכה.
- אין אינטרנט בסופר? הכל ממשיך לעבוד מקומית ומסתנכרן כשהחיבור חוזר.
- שני הטלפונים שינו את אותו פריט? השינוי המאוחר יותר מנצח.

## גיבוי והיסטוריה ישנה

**הגיסט הוא הגיבוי.** כל שינוי בשני הטלפונים נשמר בו תוך שניות. טלפון שאבד? מחברים טלפון חדש עם הטוקן והרשימה חוזרת. טוקן שאבד? יוצרים חדש, והאפליקציה מוצאת את הגיסט לבד. לכן אין באפליקציה כפתורי ייצוא/ייבוא ידניים (הוסרו ב-2026-09-21: הם לא הוסיפו הגנה, ו"ייבוא" פעל כמיזוג ולא כשחזור, מה שהיה מבלבל).

## יומן תקלות

בתחתית מסך ⚙ יש שורה בשם **יומן תקלות**. כשאין תקלות האייקון שלה אפור וכתוב "אין תקלות". כשנרשמה תקלה האייקון אדום, ושורת ההסבר אומרת כמה תקלות היו ומתי האחרונה.

**מה נרשם:**
- **כשלי סנכרון**, עם הסבר בעברית פשוטה לפי קוד השגיאה. למשל 401: הטוקן לא תקף. 403: אין הרשאה או שנחצתה מגבלת הבקשות. 5xx: תקלה זמנית אצל GitHub.
- **כשל בהתחברות** עם טוקן.
- **שגיאות קוד** שלא נתפסו, עם ההודעה והשורה.

**מה לא נרשם:** ניתוקי רשת, כי הם לא תקלה (לשם כך יש הנקודה האפורה). גם הטוקן ותוכן הרשימה לא נרשמים. אם טוקן מופיע בתוך הודעת שגיאה, הוא מוחלף ב־`[token]`.

**תקלה שחוזרת** (למשל טוקן שבוטל, שנכשל בכל רענון של 30 שניות) נאספת לשורה אחת עם מונה, כדי שלא תמלא את היומן. נשמרות 30 הרשומות האחרונות, בכל מכשיר בנפרד. היומן לא מסונכרן.

**כשהנקודה ליד הכותרת אדומה,** הקשה על הכותרת פותחת ישר את היומן.

**כדי לשלוח לי תקלה:** ⚙ ← יומן תקלות ← **העתקה לשליחה**, ולהדביק בצ'אט. הטקסט כולל את הגרסה, מצב הסנכרון וסוג המכשיר.

## תקלות נפוצות

**"החיבור נכשל, בדקו את ה-token":** ודאו שהעתקתם את ה-token במלואו ושסימנתם את הרשאת `gist`.

**שינוי מטלפון אחד לא מופיע בשני:** ⚙ ← "סנכרון עכשיו" בשני המכשירים.

**האפליקציה לא מתעדכנת אחרי העלאה:** סגרו אותה לגמרי (החלקה למעלה במסך המתגים) ופתחו מחדש.

**ריבוע ריק במקום אייקון:** חסרים קבצי אייקון בשרת, או שצריך למחוק ולהוסיף מחדש למסך הבית.
