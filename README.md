**גרסה נוכחית: 2026-09-20.** מספר הגרסה מופיע בתחתית מסך ⚙ שבאפליקציה — כך תמיד אפשר לדעת אם הטלפון קיבל את העדכון האחרון או שהוא מציג עותק ישן מהמטמון.

## שלב 1 — העלאה ל-GitHub Pages (פעם אחת)

1. github.com ← **+** ← **New repository**. שם: `kniot`, Public, צור.
2. בעמוד הרפו: **Add file ← Upload files** ← גרור את **כל** הקבצים מהתיקייה (חוץ מקבצי הגיבוי, אם לא רוצים) ← Commit.
3. **Settings ← Pages** ← Branch: `main`, תיקייה `/ (root)` ← Save.
4. אחרי כדקה הקישור יופיע למעלה: `https://<שם-המשתמש>.github.io/kniot/`

הרפו ציבורי אבל מכיל רק קוד — **הנתונים שלכם לא נמצאים בו**. הרשימה נשמרת ב-Gist פרטי.

### עדכון גרסה
אותו מסך: **Add file ← Upload files** ← גרירת הקבצים המעודכנים ← Commit. תוך דקה זה באוויר.

בטלפון: סגרו את האפליקציה **לגמרי** (החלקה למעלה במסך המתגים, לא רק חזרה למסך הבית) ופתחו שוב. כדי לוודא שהעדכון הגיע: ⚙ ← תחתית המסך ← השוו את מספר הגרסה לזה שכתוב בראש המסמך הזה.

## שלב 2 — התקנה על האייפון

1. פתחו את הקישור **בספארי** (לא בכרום — רק ספארי יודע להתקין על מסך הבית באייפון).
2. כפתור השיתוף (המרובע עם החץ) ← **הוספה למסך הבית** ← הוספה.
3. סגרו את ספארי ופתחו את האפליקציה מהאייקון.

מעכשיו אין שורת כתובת, יש מסך פתיחה שחור עם הלוגו, והיא מתנהגת כמו אפליקציה רגילה.

> **אם שדרגתם מגרסה קודמת והאייקון הישן נשאר:** iOS מקפיא את האייקון ברגע ההתקנה.
> מחקו את הסמל מהמסך (לחיצה ארוכה ← הסרה) והוסיפו מחדש דרך ספארי. הנתונים לא ייפגעו — הם נשמרים בדפדפן ובענן, לא באייקון.

## שלב 3 — סנכרון בין שני הטלפונים

### יצירת Token (פעם אחת)
1. github.com ← תמונת פרופיל ← **Settings** ← **Developer settings** (בתחתית) ← **Personal access tokens ← Tokens (classic)**.
2. **Generate new token (classic)**. שם: `kniot`, Expiration: **No expiration**, וסמנו **רק** את התיבה **gist**.
3. Generate ← העתיקו את ה-token (מתחיל ב-`ghp_`). הוא מוצג פעם אחת בלבד.

### חיבור
בכל אחד משני הטלפונים: ⚙ ← הדביקו את **אותו** token ← **התחברות**.

מרגע זה שניכם רואים ומעדכנים את אותה רשימה. נקודה קטנה ליד הכותרת מראה את מצב הסנכרון:

| הנקודה | מה זה אומר |
|---|---|
| ירוקה | מסונכרן |
| כתומה מהבהבת | מסנכרן כרגע |
| **חלולה אפורה** | **אין רשת — הכל שמור במכשיר ויעלה כשהחיבור יחזור. לא תקלה** |
| אדומה | תקלה אמיתית (טוקן פג, הרשאה נשללה) — כדאי להיכנס ל-⚙ |
| לא מופיעה | לא מחוברים לסנכרון |

ב-⚙ מופיעה גם שורת מצב במילים: "מסונכרן לפני 3 דקות", או "אין רשת · 2 שינויים ממתינים להעלאה".

## שימוש

| פעולה | איך |
|---|---|
| הוספת פריט | ＋ בפינה ← הקלדה ← Enter. יש השלמה אוטומטית ממה שקניתם בעבר |
| הוספת כמה בבת אחת | הקלידו `חלב, לחם, ביצים` — או **הדביקו רשימה שלמה** (למשל מוואטסאפ, שורה לכל פריט). הכל נכנס כפריטים נפרדים בפעולה אחת, ו"בטל" מבטל את כולם ביחד |
| קניתי | הקשה על ○ — הפריט מקבל קו חוצה והתווית "נקנה" |
| אין במלאי | הקשה על ⊗ — הפריט מעומעם ומקבל את התווית "חסר", ונשאר ברשימה לפעם הבאה |
| עריכת שם | **לחיצה ארוכה על השם** (חצי שנייה). Enter או נגיעה בחוץ שומרים, Escape מבטל |
| כמות | + ליד השם. משעולה מ-1 מופיע גם − |
| מחיקה | גרירה שמאלה |
| **סבב חדש** | ↺ בפינה — מנקה את **כל** הסימונים ומשאיר את הפריטים, כדי לקנות שוב את אותם מוצרים בלי להקליד מחדש |
| ביטול | אחרי מחיקה או ↺ מופיעה למטה הודעה עם "בטל" — הקשה עליה מחזירה את המצב |
| מראה | ⚙ ← אוטומטי / בהיר / כהה |

**הקשה על גוף השורה או על השם לא עושה כלום** — רק ○ ו-⊗ מסמנים. זה בכוונה, כדי שלא יסומנו פריטים בטעות תוך כדי גלילה.

**סדר הרשימה:** למעלה מה שעדיין צריך לקנות (החדש שנוסף ראשון), באמצע מה שסומן חסר, ובתחתית מה שכבר נקנה. פריט שמסמנים **לא זז מיד** — הסימון מופיע במקום, ורק אחרי חצי שנייה, כשהאצבע כבר הורמה, השורה מחליקה למקומה החדש. שינוי כמות או עריכת שם לא מזיזים פריט בכלל.

הרשימה היא תבנית קבועה, לא רשימה חד-פעמית: הפריטים נשארים בה גם אחרי שנקנו. בתחילת קנייה חדשה לוחצים ↺ והכל חוזר להיות "צריך לקנות". מוצר שכבר לא קונים — מוחקים בגרירה.

> **שימו לב בשימוש משותף:** ↺ משפיע על שני הטלפונים. אם אחד מכם בסופר באמצע סימון והשני לוחץ ↺ בבית, הסימונים יימחקו אצל שניכם תוך שניות. "בטל" בהודעה מחזיר את זה.

## סנכרון — איך זה עובד

- כל שינוי נשמר לענן תוך ~3 שניות.
- בכל פתיחה או חזרה לאפליקציה היא מושכת עדכונים, **וגם כל 30 שניות כשהאפליקציה פתוחה לפניכם** — כך שינוי מהטלפון השני מופיע מעצמו בלי לצאת ולחזור. הרענון הזה שקט: הוא לא מהבהב ולא מצייר מחדש אם לא השתנה כלום, ונעצר כשהאפליקציה ברקע או כשאתם באמצע גרירה או עריכה.
- אין אינטרנט בסופר? הכל ממשיך לעבוד מקומית ומסתנכרן כשהחיבור חוזר.
- שני הטלפונים שינו את אותו פריט? השינוי המאוחר יותר מנצח.

## גיבוי והיסטוריה ישנה

⚙ ← **ייצוא קובץ** שומר קובץ JSON עם כל הנתונים. **ייבוא קובץ** מחזיר אותם.

היסטוריית הקניות מהגרסה הקודמת של האפליקציה (חנויות, סכומים, מחירי פריטים) לא נמחקה. היא נשמרת מקומית, נכללת בייצוא, ובסנכרון הראשון אחרי עדכון 2026-09-19 היא נכתבת פעם אחת לקובץ נפרד בשם `kniot-archive.json` בתוך אותו גיסט פרטי. מאותו רגע היא מפסיקה להישלח שוב בכל שינוי — מה שהקטין את תעבורת הסנכרון בעשרות אחוזים.

## תקלות נפוצות

**"החיבור נכשל — בדקו את ה-token"** — ודאו שהעתקתם את ה-token במלואו ושסימנתם את הרשאת `gist`.

**שינוי מטלפון אחד לא מופיע בשני** — ⚙ ← "סנכרון עכשיו" בשני המכשירים.

**האפליקציה לא מתעדכנת אחרי העלאה** — סגרו אותה לגמרי (החלקה למעלה במסך המתגים) ופתחו מחדש.

**ריבוע ריק במקום אייקון** — חסרים קבצי אייקון בשרת, או שצריך למחוק ולהוסיף מחדש למסך הבית.

**החלפת token** — ⚙ ← ניתוק ← הזנה מחדש. הנתונים לא הולכים לאיבוד.

## מה השתנה בגרסה 2026-09-19

- **ההקשות נרשמות בפעם הראשונה.** קודם, תזוזה קטנה של האצבע נחשבה לתחילת גרירה וההקשה נזרקה בשקט — מה שגרם ללחוץ שוב ושוב על ה-✓.
- **הסימון מיידי ובמקום.** הפריט כבר לא קופץ לתחתית הרשימה תוך כדי שהאצבע עליו.
- **הסנכרון כבר לא מבטל סימונים.** אם שעון הטלפון השני הקדים, סימון טרי היה מתהפך בחזרה כמה שניות אחרי הלחיצה. עכשיו שינוי מקומי מנצח עד שהוא עולה לענן — וזה נשמר גם אם האפליקציה נסגרת באמצע.
- **אין יותר הבהוב אדום בגלילה.** פס המחיקה נוצר רק כשגרירה מתחילה.
- **הקשה על השורה לא מסמנת.** רק ○ ו-⊗, והם הוגדלו לשטח מגע של 44 פיקסלים.
- **תוויות "נקנה" ו"חסר"** ליד שם הפריט.
- **עריכת שם** בלחיצה ארוכה.
- **↺ = סבב חדש** במקום ביטול. הביטול עבר להודעה שמופיעה למטה.
- **סנכרון קל יותר**: ההיסטוריה הישנה עברה לארכיון, הקטלוג מוגבל ל-300 שמות, ואין כתיבה לענן כשאין מה לכתוב.
- **מספר גרסה** בתחתית ⚙.
- **תיקון בהוספת פריטים (09-19b):** כפתור ＋ התנהג כמתג — כשהרשימה הייתה ריקה ושדה ההקלדה כבר פתוח, הלחיצה עליו **סגרה** אותו, והפריט הראשון שהוקלד הלך לאיבוד. עכשיו ＋ תמיד פותח וממקד, ואם כבר כתוב משהו בשדה — הוא מוסיף אותו. בנוסף, רשימת ההשלמה האוטומטית נבנית רק בפתיחת השדה ולא אחרי כל הוספה, מה שהפיל באייפון את חלונית ההשלמה באמצע ההקלדה.
